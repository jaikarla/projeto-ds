# Documentação de Arquitetura - Modelo C4

Esta documentação descreve a visão de contexto e containers do sistema de gestão de BPA (Boletim de Produção Ambulatorial).

---

## Diagramas de Arquitetura (N1 e N2)
```mermaid
graph TD
    %% Nível 1: Contexto
    User((Faturista)) -- "Gerencia cadastros e gera relatórios" --> System[Sistema de Gestão BPA]
    System -- "Exporta arquivos TXT/CSV" --> SUS[Sistemas do SUS / SIA-SUS]

    %% Nível 2: Containers (Detalhamento do Sistema)
    subgraph "Sistema de Gestão BPA (Interno)"
        WebApp[Frontend Web<br/>React / HTML-CSS]
        API[API Backend<br/>Node.js / Express]
        DB[(Banco de Dados<br/>PostgreSQL)]
        
        WebApp -- "Acessa via HTTPS" --> API
        API -- "Lógica de Atendimentos e Faturamento" --> DB
    end

    %% Conexões entre Usuário e Containers
    User -- "Usa o navegador" --> WebApp
    API -- "Gera arquivo de saída" --> Files[Relatórios BPA .txt/.csv]
